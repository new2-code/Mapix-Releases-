# 🗺️ Mapix: Codebase Intelligence & Logic Mapping

**Mapix** is an enterprise-grade, local-first codebase intelligence tool designed to cure "AI Context Amnesia" and eliminate the "Folder Dance" for Senior Engineers. It mathematically parses your codebase to draw interactive, spatial architecture maps, and feeds surgical context to local AI—ensuring your proprietary code never touches the cloud.

> 🔒 **Proprietary Engine:** Mapix is a commercial application. The core engine source code is kept in a private repository to protect our high-speed parsing and logic-mapping algorithms. This public repository is strictly used to distribute the official, compiled desktop application releases.

---

## ⚡ The Core Problem
When Senior Engineers join a new team or debug a massive legacy application, they spend weeks clicking through hundreds of folders just to understand how data flows. Furthermore, when using AI coding assistants, pasting thousands of lines of code destroys the context window, causing massive hallucinations. 

## 🎯 The Mapix Solution
Mapix acts as a "Senior Architect on your second monitor."

1. **Spatial Architecture Mapping:** Mapix mathematically traces cross-file dependencies and generates an interactive 2D map of your entire logic grid. You can visually trace the "Blast Radius" of a bug from the UI straight down to the database.
2. **Context Compression:** Mapix automatically compresses your entire 100,000-line codebase into a single, highly-optimized architectural blueprint file (`mapix_index.md`). Simply drag this file into your AI editor (like Cursor or Claude), and your AI will instantly understand your entire architecture without you saying a word.
3. **100% Air-Gapped Security:** We know you cannot send proprietary enterprise code to the cloud. Mapix is built from the ground up to operate entirely on your local hardware.
